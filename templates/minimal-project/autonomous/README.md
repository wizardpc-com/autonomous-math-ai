# Autonomous adapter

`project.json` maps this project into the generic harness. Runtime evidence is
append-only; canonical project files remain behind controller and audit gates.
Each run freezes `canonical_inputs` and regenerates noncanonical planning views.
`prompts/director.md` is an optional stable-constraints overlay; current frontier
and progress always come from the dynamic canonical snapshot.

`research_memory/` is the shared structured input boundary for externally
audited exact results, reusable assets, representation bridges, method kill
gates, and campaign themes. `coordination/` is rebuilt from those inputs and is
routing-only; neither directory grants ClaimGraph authority.
