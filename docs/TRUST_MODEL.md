# Trust model

The package preserves falsification-first research, explicit evidence levels,
fresh independent audit, an append-only claim/event record, and a fail-closed
canonical gate.

Representation contracts bind every task and candidate to a branch,
localization, saturation, normalization, content convention, exceptional
factors, and combination scope. Different representation hashes cannot be
combined unless a `REPRESENTATION_BRIDGE` candidate independently passes audit.
Legacy records map to `LEGACY_UNSPECIFIED` and require the same bridge.

Output Protocol v2 keeps model output minimal. Director, worker, and auditor
schemas are bundled package resources and pass the same Structured Outputs
preflight in mock and App Server paths. The controller injects known audit and
job identity fields. Historical v1 data is accepted only by explicit replay
translation.

Mechanical workers use exactly Spark/high/null. A structured permanent
unavailable or access-denied result permits one Luna/medium/null fallback.
Timeouts, network errors, and transient App Server failures retry Spark within
bounds and never poison the availability cache. No route may use fast,
priority, Sol, Terra, a parent model, or recursive delegation.

Human steering and ingested assets are append-only inputs. They cannot set
claim trust, authorize arbitrary tasks, assert representation compatibility, or
bypass independent audit. Durable references use `project://`, `campaign://`,
or `epoch://` URIs and never depend on a machine-specific absolute path.
